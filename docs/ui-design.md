# Psyche 三端页面设计

日期：2026-08-03（UTC+8）
参考边界：移动端参考 Remodex 的远程 Codex 工作流；桌面端吸收 ChatGPT、Claude Desktop 和成熟开发工具的信息密度，不复制任何单一产品。视觉研究参考了 [Linear 官方改版说明](https://linear.app/now/how-we-redesigned-the-linear-ui)、[Figma Linear UI Kit](https://www.figma.com/community/file/1279162640816574368/linear-ui-free-ui-kit-recreated) 与 [Figma 深色生产力工作台](https://www.figma.com/community/file/1621990878990665091/modern-dashboard-ui-kit-dark-admin-panel-productivity-analytics-app-design-figma)，仅提取层级与密度原则，不复制第三方资产。

## 1. 视觉命题

Psyche 是安静、快速、可信的 Apple 原生工作台。默认采用中性深色主题，以画布、面板和浮层三档表面建立层级；浅色主题保留同一结构并可随时切换。系统蓝用于主操作和选中态，系统绿用于在线状态与开关，琥珀色用于等待，红色用于错误；珊瑚红仅保留在品牌状态点、待审批和 Diff 提醒。页面不使用营销 Hero、装饰渐变、悬浮区块、厚重阴影或卡片嵌套。

核心动效只服务三件事：状态局部更新、详情层级进入、断线恢复反馈。流式输出不让列表重排，所有固定工具栏和状态控件保持稳定尺寸。

## 2. 一级信息架构

| 页面 | 主要任务 | 默认内容 |
|---|---|---|
| 首页 | 处理当前最重要的事 | 待处理、运行任务、异常 Host、最近会话 |
| 会话 | 查看和控制完整 Codex 时间线 | 会话列表、时间线、桌面详情栏 |
| 项目 | 按工作目录组织会话 | 项目列表、分支、Host、最近会话、快捷操作 |
| 主机 | 管理执行环境和连接 | 在线状态、延迟、资源、版本、重连和终端 |
| 设置 | 管理 Workspace 与设备行为 | 密钥、Relay、Bark、缓存、更新、隐私 |

全局搜索位于桌面顶部工具栏，iPhone 通过顶部图标打开。搜索结果同时覆盖会话、项目和主机，不单独占一级 Tab。

## 3. 平台布局

### macOS

- 左侧 236px 一级侧边栏：品牌、新建任务、五个一级页面、Workspace 和 Relay 状态。
- 会话页使用三栏：288px 会话列表、弹性时间线、278px 详情面板。
- 主体最大宽度约 1160px；高频信息以列表和分隔带组织。
- 窗口缩窄时侧边栏折叠为 82px 图标栏，随后先隐藏会话详情栏。

### iPadOS

- 宽屏保留折叠图标侧边栏和双栏内容。
- 会话页默认“会话列表 + 时间线”，详情通过面板或全屏层级进入。
- 窄分屏进一步退化为 iPhone 单列导航，但信息与功能不减少。

### iOS

- 底部五 Tab：首页、会话、项目、主机、设置。
- 会话 Tab 先显示列表，点击后进入单列时间线，左上角返回。
- 输入区固定在底部；进入会话后隐藏全局底部 Tab，避免与输入区争夺触控空间。
- Plan、命令、Diff 和审批保持在发生的时间位置，默认摘要；运行、失败和等待处理项自动展开。

## 4. 首页规则

首页严格按以下顺序：

1. 需要处理：Diff 审批、命令审批、MCP 用户输入、中断后确认。
2. 运行中：任务名称、阶段、Host、持续时间和稳定进度条。
3. 主机异常：正常 Host 不占空间，仅突出离线、版本不兼容或 Relay 异常。
4. 最近会话：状态、项目、分支、Host 和更新时间。

点击任意项目直接进入对应会话或 Host 详情，不增加中间确认页。

## 5. 会话时间线

### 时间线项目

- 用户消息与 Agent 消息。
- Plan 与逐步状态。
- 命令、PTY 输出和退出结果。
- 文件修改、统一 Diff 与审批。
- MCP、Skills、Plugins、Hooks、子 Agent 和结构化用户输入。
- 网络、权限、压缩、用量、错误和恢复状态。

### 展开规则

- 普通已完成项目默认折叠为摘要。
- 正在运行、失败和等待用户处理的项目自动展开。
- 用户展开状态按 item ID 保存，不因流式 delta 丢失。
- `item/completed` 到达后局部替换最终状态，不重建整条时间线。

### 输入区

- 文本输入、附件、模式和权限在同一稳定区域。
- Plan/Code 使用分段或紧凑菜单；权限使用选项菜单。
- Enter 发送、Shift+Enter 换行；移动端提供明确发送图标。
- 运行中允许 Steer 或排队后续消息；中断按钮始终显示当前动作含义。

## 6. 页面状态

每个一级页面必须具备：

- 首次加载骨架，不显示整页 Spinner。
- 无数据状态与明确下一步动作。
- Host 离线时允许查看缓存历史，并说明哪些操作会排队。
- Relay 断开时保留本地可用内容，顶部显示恢复进度和最后 ACK。
- 版本不兼容时显示具体缺失能力，禁止把未知事件当作普通文本吞掉。
- 权限不足、审批拒绝、任务中断、同步窗口过期和缓存清理均有可恢复路径。

## 7. 原型交互清单

当前 Web 原型已经实现：

- 五个一级页面和三端自适应导航。
- 首页待处理、运行任务、Host 异常和最近会话入口。
- 会话列表与完整时间线。
- Plan、命令输出和 Diff 展开/折叠。
- Diff 批准、拒绝和撤销。
- 任务继续/中断、发送后续消息。
- 项目选择、Host 选择和重连反馈。
- 全局搜索与快捷跳转。
- 新建任务表单。
- Bark 配置、测试通知和保存反馈。
- 缓存滑块、清理确认和结果提示。
- macOS、iPadOS、iOS 设备预览模式。
- 默认深色、浅色切换和设备级主题持久化。

## 8. 可访问性与性能约束

- 图标按钮都有可访问名称和 Tooltip。
- 触控目标在移动端至少 44px 的有效区域。
- 颜色不是唯一状态信号，始终配合图标和文本。
- 支持键盘焦点、`Cmd/Ctrl + K` 搜索和 Escape 关闭浮层。
- 遵守 `prefers-reduced-motion`。
- 超长列表必须虚拟化；Markdown、命令和 Diff 解析移出主线程或分帧执行。
- 固定栏、状态徽标、进度条和工具按钮都有稳定尺寸，动态文本不得推动整体布局。
